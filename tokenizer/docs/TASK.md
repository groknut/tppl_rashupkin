
# Задача
Написать лексический анализатор (токенизатор), который превращает строку исходного кода в последовательность токенов. \
Токенизатор должен распознавать:

    идентификаторы (последовательность букв, цифр и `_`, не начинающаяся с цифры);
    ключевые слова: `if`, `else`, `while`, `return`, `for`, `def`;
    целые и вещественные литералы;
    строковые литералы в двойных кавычках;
    операторы: `+ - * / = < > == <= >=`;
    разделители: `( ) { } , ;`.

Пробелы, символы табуляции и комментарии (от `#` до конца строки) пропускаются.

Требования

    Программа должна быть написана на Python
    Должен быть файл `README.md` с пояснением того, как запустить программу
    Программа принимает путь к файлу с исходным кодом через аргументы командной строки
    Для каждого токена выводится строка в формате `(<тип>, <значение>, <строка>:<столбец>)`, где `<тип>` — `IDENT`, `KEYWORD`, `INT`, `FLOAT`, `STRING`, `OP` или `SEP`.
    Позиция указывает на начало токена.
    При недопустимом символе программа выводит ошибку категории `lexical` и завершается с ненулевым кодом возврата.
    Сообщения об ошибках выводятся в едином формате:
    ```bash
    <файл>:<строка>:<столбец>: lexical: <сообщение>
    ```

## Примеры
Входной файл:
```txt
x = y * 2 + z * 3
```
Вывод:
```bash
(IDENT, x, 1:1)
(OP, =, 1:3)
(IDENT, y, 1:5)
(OP, *, 1:7)
(INT, 2, 1:9)
(OP, +, 1:11)
(IDENT, z, 1:13)
(OP, *, 1:15)
(INT, 3, 1:17)
```

Входной файл:
```txt
`a @ b`
```
Вывод:
```bash
input.txt:1:3: lexical: unexpected character '@'
```

## Размещение решения
Программу поместить в репозиторий в директорию `tokenizer`. Файл с решением назвать `main.py`. \
Для программы должны быть написаны тесты. Итоговый результат вычисляется как процент покрытия умноженный на количество баллов!
