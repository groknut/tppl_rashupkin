
# Среднее арифметическое Assembler

## Условие задачи
Для заданного файла требуется найти среднее арифметическое между элементами двух массивов `x` и `y`. \
Для каждой пары элементов с одинаковым индексом вычисляется разность:
```txt
x[i] - y[i]
```
Затем по всем полученным разностям находится среднее арифметическое.

## Формат входного файла
Пример файла:
```
5, 3, 2, 6, 1, 7, 4
0, 10, 1, 9, 2, 8, 5
```
Для этого примера разности равны:
```
5, -7, 1, -3, -1, -1, -1
```
Сумма разностей равна -7, кол-во равно 7, среднее арифметическое равно -1.

## Требования
1. Вывод программы
```bash
filename: 10 # успешный запуск
filename: wrong data # файл испорчен
```
