
# Постфиксная нотация 
## Условие задачи
Написать стековую машину, которая вычисляет выражение, записанное в постфиксной нотации.

**Принцип работы стековой машины:**
- Обрабатывает арифметические операции: `+`, `-`, `/`, `*`
- Обрабатывает специальный оператор `~`
- Операнды и операции разделены пробелами

### Описание оператора `~`

    > Если оба операнда не равны 0: вычислить модуль разницы `|x - y|` и положить результат обратно в стек.
    > Если хотя бы один из операндов равен 0: вычисляет сумму всех значений в стеке, включая извлеченные операнды, возводит её в квадрат и кладет результат обратно в стек

### Требования
- Программа должна быть написана на Python
- Должен быть файл `README.md` с пояснением того, как запустить программу
- Программа принимает выражение через аргументы командной строки
- Программа выводит результат в формате: `выражение = результат`
- Программа должна выводить состояние стека на каждом шаге вычисления
- Программа должна быть заботливой

### Примеры выражений
```bash
3 0 4 ~ 2 ~
```
```bash
2 2 + 4 - 4 ~ 2 3 * +
```
