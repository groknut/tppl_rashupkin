# Задание
Для каждого предложенного варианта выбрать парадигму и язык программирвоания и пояснить почему сделан именно этот выбор.

# Задачи

## 1. Обработка больших данных в реальном времени

Разрабатывается система обработки научных данных.

Система должна:

* Обрабатывать поток изображений 100 кадров в секунду с разрешением 4096 на 4096 и 16 бит на пиксель
* Выявлять испорченные изображений при помощи математических функций
* Работать 24/7 без остановок


## 2. Прототип ML-сервиса для прогноза погодных условий
Разрабатывается система для локального прогноза погодных условий по сети метеорологических датчиков.

Требования:

* Запустить MVP за 2 недели
* Прогноз осуществляется 1 раз в сутки
* Использовать готовые ML-библиотеки
* Важно быстро итерировать и менять алгоритмы


## 3. Интерактивный UI для торгового терминала
Разрабатывается веб-интерфейс для трейдеров.

Требования:

* Отображение 50+ виджетов с данными в реальном времени
* Мгновенная реакция на действия пользователя (< 16 мс)
* Сложные взаимодействия между виджетами (изменение в одном обновляет другие)
* Потоки данных из WebSocket, REST API, локальных событий
* Код должен быть легко тестируемым


## 4. Прошивка для устройства регистрации температуры

Разрабатывается прошивка для умного датчика температуры.

Требования:

* Микроконтроллер с 256KB Flash и 32KB RAM
* Работа от батареи (минимальное энергопотребление)
* Прямой доступ к регистрам GPIO, ADC, UART
* Детерминированное время отклика (real-time)
* Код должен быть переносимым между разными микроконтроллерами
