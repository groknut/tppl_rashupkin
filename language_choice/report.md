
# Задание
Для каждого предложенного варианта выбрать парадигму и язык программирвоания и пояснить почему сделан именно этот выбор.

# Задачи

## 1. Обработка больших данных в реальном времени
**Парадигма:** Императивная \
**Язык программирования:** C++ \
**Обоснование:** 
- Математический анализ кадров ложится на GPU
- Имеется богатая экосистема библиотек: OpenCV, FFTW
- Никакого сборщика мусора

## 2. Прототип ML-сервиса для прогноза погодных условий
**Парадигма:** Императивная + ООП/Декларативное + Функциональная \
**Язык программирования:** Python \
**Обоснование:**
- Реализация MVP за 2 недели: необходима максимальная скорость разработки
- PyTorch (если используем): Модель - как класс
- Tensorflow (если используем): декларативное описание модели
- Прогноз 1 раз в сутки: производительность языка не критична, ресурсоемкие задачи делегируются библиотекам на C
- Большая экосистема библиотек
- Императивный цикл обучения

## 3. Интерактивный UI для торгового терминала
**Парадигма:** Реактивная и декларативная \
**Язык программирования:** Typescript \
**Обоснование:** 
- Строгая типизация в отличие от JS
- Данные с сервера WebSocket и REST API идут непрерывно
- Необходимо автоматическое обновление виджетов при изменении данных без перерисовки остальных жлементов

## 4. Прошивка для устройства регистрации температуры
**Парадигма:** Императивная \
**Язык программирования:** C \
**Обоснование:** 
- Ограниченные ресурсы
- Прямой доступ к железу
- Большая экосистема проектов
- Переносимость между разными микроконтроллерами
